# Agenda do Instagram da dgenny (@dgenny.ai)

Publica automaticamente, de 28/10 a 31/12/2026, uma peça por dia, alternando:
- **Post no feed às 08:00** (horário de Brasília)
- **Story às 16:00**

Arquivos: `agenda.json` (o que sai e quando), `img/` (artes), `publicados.json` (registro do que já saiu).
O GitHub pode atrasar o disparo em alguns minutos. Para pausar, desative o workflow em Actions.
